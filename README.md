# 🎵 Экспертная система «Подбор музыкального инструмента»

Учебное приложение на Python/Tkinter к практическому занятию
«Построение экспертной системы на имитационном принципе»
(лекция «Построение модели в виде оценочной функции», курс «Моделирование систем»).

Система **сама** строит линейную модель `Yj = a1j·x1 + … + anj·xn` по примерам
(режим обучения «кнут и пряник»), отвечает, какой инструмент больше подходит под
заданные признаки (режим экспертизы, принцип демона — «кто громче крикнет, тот и
прав»), объясняет «почему», и **автоматически адаптируется**: при любой правке базы
знаний или при ответе «мира» «это неверно» она переобучается/доучивается.

## Запуск

**Windows**: двойной щелчок по `run.bat` (сам поставит зависимости) или

```bat
py -3 -m pip install -r requirements.txt
py app.py
```

**Linux / macOS** (нужен `python3` с tkinter — `sudo apt install python3-tk`):

```bash
./run.sh
```

Зависимости: `numpy`, `matplotlib` (графики), `sv-ttk` (современная тема оформления,
необязательна — без неё используется встроенная тема).

Автотесты ядра: `python -m pytest tests`.

## Метод (кратко)

* Матрица `aij` (строки — признаки, столбцы — классы) изначально нулевая.
* **Обучение.** «Мир» предъявляет пример; система отвечает (max Yj); если ответ
  неверен (или равные голоса — «не опознан»), вектор примера, умноженный на шаг `h`,
  **прибавляется** к столбцу верного класса и **вычитается** из остальных.
  В успешном случае модель не меняется. Эпоха — проход по всем примерам, затем
  экспертиза всех примеров; обучение идёт до нуля ошибок (или до предела эпох).
* **Нормализация** (по желанию) возвращает коэффициенты в гиперкуб `[-1; 1]`.
  Без нормализации шаг `h` на решение не влияет (argmax инвариантен к масштабу);
  с нормализацией малый шаг — «консерватизм», большой — «разболтанность».
* **Экспертиза.** Вектор демонов `Y = X·A`; побеждает максимум; отрыв от второго
  места — уверенность. Неопределённый признак = 0.5.
* **Прогноз.** Неизвестный объект относится к самому похожему классу.
* **Дообучение.** Если «мир» сообщает, что ответ неверен, пример запоминается и
  система доучивается, пока снова не опознаёт все примеры.

База знаний по умолчанию: 8 инструментов × 8 признаков из лабораторной
(Скрипка, Гитара, Электрогитара, Флейта, Барабан, Ксилофон, Пианино, Синтезатор;
Струнный, Смычковый, Щипковый, Духовой, Клавишный, Ударный, Электрический, Деревянный).
